轻时钟 LiteClock

启动
下载 Release 压缩包后完整解压，双击其中的 LiteClock.exe 即可运行；从源码构建则运行 dist\LiteClock-x64\LiteClock.exe。分发时保留整个目录。再次运行会打开设置，不会重复启动多个时钟。
无配置时的默认显示：三行“时:分:秒 / 月-日 / 周几”，微软雅黑 UI 8pt 加粗、黑字、浅蓝背景。
默认宽 68、高 46，距屏幕右侧 0、底部 56，尺寸使用 Windows 逻辑像素。

日常操作
• 右键时钟 → 设置，或双击时钟。
• 拖动时钟最左侧约 7 像素的区域，直接改变宽度，右侧保持不动。
• 按住 Shift 拖动时钟，可以移动位置。
• 中键默认复制当前三行文字。
• 系统托盘图标可打开设置、重置位置或退出。
• 设置窗口打开时，直接拖动调宽/移动暂时停用，避免与设置预览互相覆盖。

自定义
内容：最多 8 行，自定义日期时间格式和固定文字、日期语言、时区、时间偏移、刷新频率。
布局：宽高、右侧和底部距离、显示器、水平/垂直对齐、四边内边距、文字偏移、行高、行间距。
文字：字体、字号、粗体、斜体、下划线、颜色、透明度；每一行都可单独设置或隐藏。
外观：背景颜色、背景和整体透明度、圆角、边框宽度/颜色/透明度、悬停颜色。
操作：置顶、全屏隐藏、锁定、鼠标穿透、单击/双击/中键动作、提示文字和开机启动。
应用信息：查看版本、界面框架、运行环境、操作系统、程序位置和配置文件路径；“复制应用信息”可复制这些信息。设置和日历标题栏同步显示版本号。
随系统启动：在“操作”页顶部开启“随系统启动”，点击“保存”后，下次登录 Windows 自动显示时钟。关闭开关并保存可取消自启动；取消或关闭设置不会更改启动项。默认关闭，只对当前用户生效。
逐行修改样式时，先选中该行，再勾选“这一行使用独立样式”。
所有颜色项的“选择…”面板底部都有“屏幕取色”。点击后设置窗口暂时隐藏，屏幕显示取色时刻的静态画面。
移动鼠标查看像素放大图与 #RRGGBB 色值；左键确认，右键或 Esc 取消。支持跨显示器取色，取消不会更改颜色。
确认后颜色自动回填并实时预览，点击“保存”后保留。屏幕快照只在内存中使用，不保存为图片。
所有数字输入框均可直接输入、点击右侧上下按钮或按 ↑/↓ 调整；长按按钮可以连续增减。
数字框获得焦点后可用滚轮调值，未聚焦时滚轮继续滚动页面。字号/行高等使用小数步长，刷新间隔按 50 毫秒增减。
数字范围显示在输入框旁，辅助功能也会读取范围和步长。编辑时允许暂时清空或输入负号；无效、超出范围的数值会标红，修正后才能保存。
手动输入保留合法的小数精度；上下按钮按该字段的步长调整。支持小数的字段也可输入科学计数法。
鼠标穿透后，可从系统托盘或再次运行程序进入设置。
右键设置菜单固定保留，防止配置点击动作后失去设置入口。

保存、取消与配置文件
设置即时预览到桌面时钟。保存后保留；取消或关闭窗口会回到最后一次保存的状态。
设置右上角使用与桌面时钟相同的 WinUI 3 组件实时显示，包含自定义换行、逐行样式、尺寸、间距、边框和透明度。
预览默认按 100% 显示；超过预览区域时等比缩小，下方标明比例，不会改变实际时钟尺寸。
导出：把当前设置保存为 JSON。导入：载入 JSON 预览，点击保存后生效。
所有显示设置保存在程序旁的 settings.json，保存时自动保留 settings.json.bak。
如果配置损坏，程序尝试读取备份；两者都不可用时回到默认样式，并给出托盘提示。
恢复默认样式按钮恢复应用内置的默认样式。
可以移动整个 LiteClock 文件夹；若启用了开机启动，移动后应重新勾选保存，以更新路径。

与 ElevenClock 的关系
这是独立实现，不依赖 ElevenClock、Python 或 Qt，也不修改 ElevenClock 的配置。
轻时钟默认不设置开机启动。如需长期替代，可在“操作”页启用轻时钟的开机启动，并关闭 ElevenClock 的开机启动，避免重叠。
使用 Windows 本地系统时间；没有移植 ElevenClock 独立的网络对时功能。
一个实例显示一个时钟，可选择显示器。多屏混合 DPI、远程桌面和长时间运行尚未完整验证。
窗口按目标显示器的 DPI 定位，并响应显示器和 DPI 变化；混合 DPI 环境仍需实机验证。

源码和构建
全部界面使用 WinUI 3 / Windows App SDK 1.8，C# / .NET 8 实现，无 WPF 或 WinForms 依赖。
scripts\build.ps1 使用 .NET SDK 编译并发布到 dist\LiteClock-x64；首次构建需要网络还原 NuGet 包。
源码位于 src\LiteClock，按控件、窗口、模型、服务、取色功能和系统集成分组。根目录 LiteClock.sln 可直接打开工程。
构建要求 Windows 10 2004（19041）或更新版本和 .NET 8 SDK（或更新版本）。
发布目录包含运行时依赖；运行用户不需要单独安装 .NET 或 Windows App Runtime，不能仅复制 EXE。
首次构建会复制项目原有 settings.json 到发布目录，后续构建不会覆盖发布目录中的配置。
原有版本与新版使用相同默认单实例标识；迁移时先退出旧版，再启动新版。
如需自动启动，请在新版重新开启对应选项，将登录启动路径更新到发布目录。
图标文件必须与发布的 EXE 一起保留。scripts\build-icon.ps1 可以从 src\LiteClock\Assets 中的 PNG 重新生成 ICO。
命令行：--settings 打开设置；--exit 退出当前配置目录的实例。
--settings-dir <目录> 可指定独立配置目录，同一目录共享一个实例。
--self-test <结果文本路径> 执行日期、时区和配置测试。
scripts\run-tests.ps1 执行全部回归测试；scripts\run-number-tests.ps1 执行数字规则和真实 WinUI 控件测试；结果保存在 artifacts\tests。
UI 测试使用独立配置目录，需要登录后的交互式桌面。
错误信息保存在配置目录 LiteClock.log，日志有大小上限。
